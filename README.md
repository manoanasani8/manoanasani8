## Featured project

### [Banking Transaction Data Pipeline](https://github.com/manoanasani8/banking-data-pipeline)

[![Pipeline tests](https://github.com/manoanasani8/banking-data-pipeline/actions/workflows/tests.yml/badge.svg)](https://github.com/manoanasani8/banking-data-pipeline/actions/workflows/tests.yml)

A runnable Python and SQL project that validates synthetic bank transactions, logs rejected rows with reasons, and publishes daily debit, credit, and net-flow metrics in SQLite.

| Example run | Result |
| --- | ---: |
| Valid transactions loaded | 1,000 |
| Deliberately defective records rejected | 6 |
| Automated tests | 6 |

The project stores money in integer cents, preserves a rejection audit trail, and can rerun the same batch without duplicating records. [View the architecture and run it locally](https://github.com/manoanasani8/banking-data-pipeline#run-it).
